# Security and data handling

This repository is designed for public release. It must not contain:

- Amazon ML Challenge train or test data;
- leaderboard prediction or candidate-pair files;
- trained competition models, vectorizers, or pruning masks;
- AWS credentials, keys, tokens, account identifiers, or private URLs;
- local absolute paths, caches, checkpoints, or virtual environments.

Please report accidental disclosure privately to the repository owner rather than opening a public issue containing the sensitive material.
